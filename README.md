# ICTU × CodeGym Training Management Frontend
Frontend application for the ICTU × CodeGym Vietnam Training Management System.
## Technology
- React
- TypeScript
- Vite
- Oxlint
## Requirements
- Node.js
- npm
## Development
Install dependencies:
    npm install
Start the development server:
    npm run dev
Run lint:
    npm run lint
Build for production:
    npm run build
This repository currently contains the frontend foundation only. Business features will be implemented after requirements and the Product Backlog are agreed upon.
